# Content, Community and Learning Applications

This application is intended to help creators, community participants, teams, and learners create and use media, knowledge, and shared experiences. It supports organizing useful material, making it discoverable, and enabling people to publish, explore, or learn from it.

## Objectives
- Create and organize media, articles, documentation, or learning material.
- Publish and share content with its intended audience.
- Help people discover relevant material and participate in community or learning activities.

## Representative workflow
A content author prepares a collection of material, organizes it for the intended audience, and publishes it. Readers or learners discover the collection and use the relevant articles, media, or learning activities. The author reviews the material and updates it as the collection develops.
